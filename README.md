# Flower Lab

A tabletop cabinet for one plant: light on a schedule, water when the soil is dry, and an NPK probe in the pot. An Orange Pi Zero 3 runs the loop through a PCA9685 and an ADS1115, and posts every reading to the main server.

The system diagram — plant, pumps, and the Orange Pi wiring — is in [concept.html](concept.html). Open it in a browser.
