# Flower Lab

A tabletop cabinet for one plant: light on a schedule, water when the soil is dry, and an NPK probe in the pot. An Orange Pi Zero 3 runs the loop through a PCA9685 and an ADS1115, and posts every reading to the main server.

The product page — one pipe up, a drip ring on the soil, probes, computer, and ethernet — is in [concept.html](concept.html). Open it in a browser.

Module notes are in [docs](docs/README.md): system design, data models, API design, and hardware control.
